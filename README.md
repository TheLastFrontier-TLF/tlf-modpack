# Modpack de The Last Frontier

Modpack de cliente para jugar en **The Last Frontier** (`play.lastfrontier.pro`).
Minecraft **1.20.1** con **Forge 47.4.18**.

## Descarga

**[Descargar la última versión (TLF_modpack.zip)](https://github.com/TheLastFrontier-TLF/tlf-modpack/releases/latest/download/TLF_modpack.zip)**

Las novedades de cada versión están en [Releases](https://github.com/TheLastFrontier-TLF/tlf-modpack/releases).

## Instalación

Vale para cualquier launcher (Prism, CurseForge, Modrinth, oficial):

1. Crea o abre una instancia de Minecraft 1.20.1 con Forge 47.4.18.
2. **Borra todo lo que haya en la carpeta `mods`** de la instancia y pon los
   jars de la carpeta `mods` del zip. Si mezclas versiones viejas y nuevas
   del mismo mod, el juego no arranca.
3. Copia la carpeta `config` del zip encima de la de la instancia
   (sobrescribe los archivos que pregunte).

Al actualizar, repite los pasos 2 y 3 con el zip nuevo.

## Solo se entra con el modpack oficial

Al conectarte, el servidor comprueba tus mods. Si tu instancia no coincide con el
modpack oficial (mods de más, jars cambiados o una versión antigua), no te deja
entrar y te dice el motivo. Además del modpack solo se admiten estos mods de
cliente: Oculus, Distant Horizons, tlskincape, AppleSkin, JEED y ocuwheel.

No incluye shaders. Si quieres usarlos, puedes añadir Oculus por tu cuenta.
